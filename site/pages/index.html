API

Uma rota, três parâmetros. A resposta é um único SVG com todos os ícones pedidos — é o que faz o README carregar uma imagem em vez de dez.

GET /icons

Parâmetro Valores Padrão
i ou icons IDs separados por vírgula, ou all obrigatório
t ou theme dark · light dark
perline inteiro de 1 a 50 15

ID desconhecido devolve 400 nomeando quais não existem, em vez de renderizar um espaço vazio.

Metadados

  • GET /api/icons a lista de IDs
  • GET /api/manifest cada ID e o arquivo por tema
  • GET /api/svgs todos os SVGs em JSON
  • GET /svg/<Arquivo>.svg o arquivo estático, servido pela CDN
